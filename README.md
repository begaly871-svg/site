## Интерактивная симуляция

Самостоятельный симулятор планетных орбит на Canvas. Звезда и планеты влияют на гравитацию; при сближении возможны возмущения и столкновения. Курсор притягивает тела, а перетаскивание перемещает обзор. Доступны добавление планет, пауза, перезапуск, скорость, масштаб и полный экран. **Оригинальные звуки по умолчанию выключены**; звук синтезируется самим браузером, можно настроить громкость.
