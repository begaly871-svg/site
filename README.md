# ORBIT® — цифровая студия

Самостоятельный интерактивный концептуальный проект дизайн-студии из Бишкека. Статический сайт, без сторонних изображений, музыкальных файлов, шаблонов и библиотек симуляции.

## Проекты

- **AUREL** — оригинальный концепт айдентики и предметного интернет-магазина.
- **NOIR RUN** — оригинальная спортивная концепция цифровой рекламной кампании.
- **FORME** — оригинальная архитектурная концепция генеративного сайта.

Все кейсы демонстрационные и созданы для проекта ORBIT; реальные заказчики и платные сотрудничества не заявляются.

## Симуляция

- Самостоятельно созданный гравитационный симулятор на Canvas: взаимное притяжение, встречи планет, возмущения и изменение орбит.
- Перетаскивайте поле мышью или пальцем, чтобы перемещать камеру. Прокрутка приближает и отдаляет вид.
- Ползунок масштабирования, скорость времени, добавление планет, пауза, перезапуск и полноэкранный просмотр.
- **Звук изначально выключен.** По желанию можно включить новые мелодичные звуковые эффекты и очень тихий атмосферный звук. Всё создаётся осцилляторами браузера; оригинальные аудио и сторонние музыкальные записи не используются.

Откройте `index.html` в браузере. Для запуска автопубликации сохраните файлы в корень репозитория и отправьте изменения в ветку `main`; проверяйте вкладку Actions и актуальную ссылку в разделе Pages этого репозитория.
