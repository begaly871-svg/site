## Интерактивная симуляция

Самостоятельный симулятор орбит на Canvas с гравитационными возмущениями, взаимодействием планет и обработкой столкновений. Двигайте курсор, перетаскивайте камеру, пользуйтесь масштабированием, регулируйте скорость и добавляйте планеты. Звуковые эффекты и низкий атмосферный фон синтезируются средствами браузера; **по умолчанию звук выключен**, его громкостью можно управлять.
